# AlignIF 数据管线复现笔记（进行中）

> 目标：亲自跑通 AlignIF 的数据处理管线（BGSU 下载 → 过滤 → US-align 聚类 → 簇级划分 + 时间隔离），对照官方数据验证，避免"想当然"。

## 一、官方数据（Zenodo 10.5281/zenodo.20528802，2026-08 获取）调查结论

### 1. 官方划分（split.pt）
| 集合 | 链数 |
|---|---|
| train | 7,669 |
| val | 129 |
| test | 158 |
| independent | 186（2024 年新释放 176 + 结构不相似老 RNA 8 条） |
| **合计** | **7,956**（论文正文写 7,932，差异待查） |

- **时间隔离严格成立**：train 全部 ≤2024-05-01 释放（2024 年内 358 条均为 2024-01~05 月）；independent 主体现 2024-05-01 后新释放（另混入 8 条 2010-2016 的老结构——说明 independent 的定义是"时间隔离 **或** 结构不相似"，双重隔离）
- **独立测试集示例**：9DTR、9DR1、8RO1、9ESI、8HZD 等 2024 新结构

### 2. 官方数据处理格式
- `pdbs/` 目录：8,115 个链文件（> split 合计 7,956 → 多出 159 个，含 independent 及冗余）
  - 命名 `PDBID_chain.pdb`；**多链组合用 `-` 连接**（如 `4K4Z_B-C-D.pdb`，1,291 个文件含 `-`）——同一 PDB 内多条 RNA 链被合并为一个样本
  - 格式：标准 PDB 全原子（含碱基原子），链统一重命名为 A
- `tmscores/`：8,115 个 .pt，**每个文件 = 该链与全部链的两两 TM 分数**（稀疏全矩阵，每文件 7,955 键）
  - TM 分数对称（验证 4TVX_X↔1ET4_A 双向 = 0.14447）
  - 链名有大小写变体（6X5M_r / 6X5M_R 并存），文件名与 split 链名需不区分大小写匹配
- `grnade_data.pt`：按序列聚合的训练特征（coords 多状态坐标 / ids / chain_ids / ss 二级结构矩阵；序列中 `_` = 缺口）

### 3. 官方聚类（499 簇）的算法还原
- 对 7,956 条链做 TM≥0.45 **连通分量** → 1,541 簇（含 5,935 链巨型簇）——❌ 不是官方算法
- 对 7,956 条链做**增量代表聚类**（簇首链为固定代表）→ 894 簇（最大 2,046）——❌ 仍偏多
- **官方 499 簇 = qTMclust**（pylelab 工具：CD-HIT 序列预聚类 + 代表增量比对 + HwRMSD/TMfast 快速预筛）——已编译安装
- 结论：**聚类算法选择直接决定簇数**（连通分量 1,541 vs qTMclust 499），防泄漏评估必须用与官方一致的 qTMclust

## 二、我们的复现管线（data/ 目录脚本）

```
01_download_pdb.py  BGSU 索引（/pdb/data API，27,728 条目含 release_date）
                    → 下载训练窗(≤2024-05-01, 23,115) + 测试窗(2024-05-01~2025-01-01, 1,137) PDB
02_parse_chains.py  纯文本解析：REMARK 2 分辨率 + 链级残基类型判定（RNA/DNA/protein/mixed）
                    → 过滤：分辨率<4Å、16-512nt、纯 RNA 链
03_split_chains.py  每条 RNA 链 → 独立 PDB 文件（链重命名 A）+ chain_list.txt
04_cluster.py       qTMclust -TMcut 0.45 -ter 3 -split 0
05_split_sets.py    簇级划分（对齐 399/50/50 比例）+ 时间隔离（release_date 判定）
```

## 三、关键发现与数据事实（对项目数据管线设计的直接启示）

1. **BGSU 索引 23,115 条（≤2024-05-01）vs AlignIF 过滤前 14,237**——差异来源待解析后确认（可能：BGSU "RNA-containing" vs "RNA-only" 判定，或链级 vs 条目级计数）。23,115 是含 RNA 的 PDB 条目数；14,237 更可能是 BGSU 解析后的 RNA 链样本数
2. **RNA 数据冗余极高**：tmscores 中 19-25% 的链对 TM≥0.45——比 RNA-FrameFlow 报告的 342 簇/5,319 条更夸张；聚类防泄漏是刚需
3. **大小写**：PDB 链 ID 区分大小写（r ≠ R），但两链同源——不区分大小写聚合可减少冗余
4. **多链样本**：AlignIF 把同条目多 RNA 链合并（4K4Z_B-C-D），我们的切链脚本目前按单链切——需要对照时注意此差异
5. **时间戳来源**：BGSU /pdb/data API 提供 release_date（截止 2026-08-12），是时间隔离划分的数据基础
