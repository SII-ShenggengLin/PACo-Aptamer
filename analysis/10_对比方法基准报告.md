## 一、评估协议与口径

### 1.1 恢复率口径（铁律：两口径选一，严禁混用）

- **池内 best**：每条链取采样池中与 native 同一度最高者，再对链集取均值。主口径。
- **t=0.1 真均值（mean-of-pool）**：t=0.1 样本逐条算恢复率后取池内均值，再对链集取均值。辅证口径（反映采样分布质量而非上界逼近）。
- ⚠️ 历史教训：旧版曾把"t=0.1 池内 best"与"t=0.1 真均值"混填同一列（A/B 层对比"55% 虚高"假结论即由此而来）。本报告所有表格两口径分列，绝不混用。

### 1.2 采样池（各方法不一致，对比时已注明）

| 方法 | 采样池 | 说明 |
|---|---|---|
| TACoAptamer / RhoDesign / gRNAde | 3 温度（0.1/0.5/1.0）× 100 = **300** | 长链自适应降采样（RhoDesign >200nt 50/温度、>400nt 30/温度） |
| AlignIF | t=0.1 × **20**，use_msta=False | 无 MStA 检索，与其他方法同输入口径 |
| NA-MPNN | t=0.1 × **10** | 官方推理脚本默认 |

池越大 best 越逼近上界——**池内 best 口径对 10/20 池方法（NA-MPNN/AlignIF）略不利**，跨方法比较以 t=0.1 均值为辅证。

### 1.3 native 真值与特殊位处理

- **B 层（test 477）**：`survey/canonical_v2.json` 的 seq（51 号构建，"结构内容"口径——以 PDB 实际坐标为准，含 5' 转录 G 等；与 manifest 有 1,237 条边缘差异已记录 library_mismatch）。
- **A 层（indep/zs 289）**：`grnade_out_v2/{stem}.native`（manifest 口径，各方法内部一致）。
- native 中 **'N' 未知碱基位跳过评估**（分母不含这些位）。
- **NA-MPNN 缺 C1' 坐标链**：官方解析器丢弃缺 C1' 残基、输出短于 native 且无位置标记 → difflib 对齐 native 得有效位集合，仅在有效位上评（与 48 号 A 层口径一致；61/64/69 号同款逻辑）。未知 token 位（parsed 中 '?'，如 5NFV_B 首端修饰残基）不进有效位。
- **AlignIF 输出 '-' 填充位**（C4' 无坐标残基）：评估跳过该位。

### 1.4 界面恢复率

- 界面定义：配体 5.0Å 口袋内 RNA 残基（44 号标注，`eval_inputs_v2/`）。
- ⚠️ **小界面饱和效应**：v2 界面链集中绝大多数界面仅 1-2 残基（A 层 59 链中 50 条 ≤2 残基；B 层 45 链同分布），池内 best 在 1-2 残基界面上极易满分（各方法界面恢复率 72-97% 即此效应）——**界面绝对值不可跨方法/跨划分比较，唯一稳健口径是"界面-整体差"**（同方法内自比）。
- TACo 评估脚本不保存采样序列池 → 不产出界面指标（如实标注，非失败）。

### 1.5 scTM 结构指标：预测器钳制（定性说明）

- 实测 **scTM 评估上界 0.366**（天然序列 → RhoFold 复折叠 → vs 天然结构，全评估集平均）——预测器精度钳制了任何方法可达的 scTM 上限，绝对通过率（TM≥0.45）仅 ~1%。
- 因此 **scTM 只作方法间相对排序的定性参考，不进主表、不作绝对结论**；主表指标为序列恢复率体系（best / t=0.1 均值 / 界面差）。

## 二、数据划分 v2 与阈值依据

### 2.1 splits_v2（唯一权威划分）

- 流程：41a 序列库 → 41b CD-HIT 序列聚类 → 41c 与结构簇传递闭包合并 → 41d 出划分。
- 规模：train 5,773 / val 96 / **test 477**（簇级 holdout）/ independent_test 235 / zero_shot_targets 93。
- zs 构成：93 = 54（配体未见 ∩ test）+ 39（配体未见 ∩ indep），是**配体不可见条件的叠加视图**（与 test/indep 有链重叠，解读时注明）。
- 防泄漏有效性实测：旧划分 → v2 划分，A 层四方法官方权重恢复率全部回落（-3.8 ~ -9.8pp），旧高分确证部分来自同源记忆。

### 2.2 阈值依据（已固定，不再参数化）

**TM 0.45（结构聚类，US-align/qTMclust）**
1. **AlignIF 官方口径**：AlignIF 论文/数据管线结构聚类阈值即 TM 0.45，引用其口径保证与文献可比。
2. **TM-score 统计性质**：TM > 0.5 通常视为同一折叠，0.45 略保守，把边界附近的同折叠结构也归并（更严格防泄漏）；随机对 TM 均值 ~0.17，0.45 距随机很远。
3. RNA 26/27 原子坐标对齐下 TM 尺度与蛋白相当（US-align v20260328 TM1 口径实测）。

**CD-HIT 0.8（序列预聚类，-n 4）**
1. **核酸序列聚类惯例**：CD-HIT 对核酸推荐 -c 0.8 -n 4（word size 4 文档默认），85-90% 常用于 rRNA/tRNA 去冗余。
2. **补 TM 盲区**：TM 聚类对"同序列不同构象"（多构象晶体）不敏感，CD-HIT 0.8 序列预聚类补上（v2 = 两类聚类传递闭包：CD-HIT 723 簇 ∪ TM 簇 → 300 簇）。

**决策记录**：阈值在 2026-08-15 用户决策中固定不再参数化（口径固定本身消除参数空间）。如审稿人要求敏感性分析，可用 41b/41c 管线一次性补 0.40/0.35 变体。

### 7.3 解读

1. **SS 条件是最大单点杠杆（-3.28pp）且长训练追不平**：旧划分下 no_ss 曾被长训练追平（S1 终值 Δ≈0）——那是泄漏记忆替代了 SS 信息；v2 堵死记忆通道后，SS 配对约束提供的是**不可被记忆替代的归纳偏置**，真实贡献 ~3.3pp 显现（t=0.1 口径 -3.57pp 同向）。佐证：S1 val 96 链小验证集上 no_ss ≈ 完整（灵敏度不足），SS 贡献在 test 477 才显著。
2. **配体/界面贡献噪声级**：no_iface -1.00pp / no_ligand -0.84pp（<1pp）——S2 复合物微调在 v2 下无显著增益，结合建模仍需更强代理目标（立项文档 8.2 风险项）。
3. **杠杆排序**：SS 条件（-3.28pp）≫ 界面加权（-1.00pp）≥ 配体上下文（-0.84pp）> 数据增强（-0.36pp）。SS/碱基对条件化是本方法相对 RhoDesign no_ss 变体的关键结构优势，也是主表打平背景下的差异化证据。
4. **no_aug 噪声级**：-0.36pp（t=0.1 口径 +0.47pp 反向）——坐标噪声 σ=0.1Å + 随机旋转在当前规模无显著增益，论文不以此为卖点。

## 八、ODesign 评估可行性（结论沿用）

**ODesign 无法纳入正式对比协议**，原因有二：
1. **小分子靶标不支持**：ODesign 的 RNA 生成只支持蛋白靶标（protein-binding RNA：输入蛋白 PDB + hotspot + RNA 长度），**没有 ligand→RNA 方向**。我们的 zero_shot 靶标集（SAM/ATP 等 56 种小分子）是其架构盲区。
2. **蛋白靶标评估样本不足**：评估集（indep + zs）中含蛋白的复合物仅 1 个条目（8PNQ），蛋白靶标 RNA 设计需专门的 RNA+蛋白复合物评估集（非适配体任务口径）。

含义：「靶标条件化 RNA 适配体（小分子靶标）」在 ODesign 中是空白——本项目方法的差异化空间被实证强化。ODesign 保留为 discussion 定性对照（无正式数字）。部署已就绪（odesign_eval 环境 + odesign_base_na_rigid.pt 权重 + 自建 CCD 库 50,941 条目），未来扩展 RNA-蛋白方向可复用。
