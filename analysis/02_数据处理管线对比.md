# RNA 设计论文数据处理管线对比（可复现性评估）

> 基于 6 篇论文 Methods 逐行提取（2026-08），用于指导本项目数据管线设计。
> 结论先行：**推荐复现 AlignIF 管线**（轻量、严格双隔离、适配体相关），RhoDesign 管线（适配体任务对口）作为第二选择。两者都优先于 NA-MPNN（TRANSFAC 不可分发）和 RNAbpFlow（AF3 Docker 蒸馏负担重）。

---

## 一、六篇论文数据管线速查表

### 1. NA-MPNN（bioRxiv 2025，Baker 实验室）
- **数据源**：PDB 官方快照 2025-01-21，直接过滤全库（不经 RNA 清洗层）
- **清洗**：重原子≥100；覆盖率≥0.9；分辨率≤3.5Å 或 NMR；occupancy>0.8；聚合物≤6000nt；UNK>20 排除 → **15,657 条核酸链**
- **聚类**：蛋白链 CD-HIT `-c 0.4 -aL 0.9 -aS 0.9`（6,658 簇）；核酸链 CD-HIT-EST `-c 0.8 -n 4`（U→T、非规范→X 预处理，9,849 簇）
- **划分**：设计任务按**核酸链簇** 10%/10% 留出（4,864/609/619）；特异性任务按**蛋白链簇**（5,328/665/665）；10 个伪结 PDB 强制进测试集；测试集组成：39 DNA-only / 88 RNA-only / 237 protein-DNA / 139 protein-RNA；RNA 单体 63 条
- **蒸馏**：RFNA/RFAA 对 CIS-BP+TRANSFAC 复合物预测，interface pAE≤6 且 pLDDT≥0.85 → 29,460 复合物
- **复现障碍**：TRANSFAC 商业授权不可再分发（蒸馏数据减 72%）；RFNA/RFAA 服务器级计算

### 2. AlignIF（Nat. Comput. Sci. 2026，上海交大）★ 推荐复现
- **数据源**：BGSU RNA 3D Hub，**双时间窗快照**：训练窗 ≤2024-05-01（14,237→过滤后 7,932 条）；独立测试窗 2024-05-01→2025-01-01（1,797→1,129 条）
- **清洗**：分辨率<4Å；长度 16–512 nt
- **聚类**：US-align TM>0.45 → **499 个结构簇**；簇内 MStA 深度上限 16
- **划分**：按簇整体划分：训练 399 簇/7,669 条、验证 50 簇/129 条、测试 50 簇/158 条；独立测试集 186 条（时间隔离 + TM<0.45 双重隔离）
- **蒸馏**：AF3 仅 50 条 RNAcentral 序列（20–510nt、10nt 递增）补充折叠多样性
- **防泄漏细节**：设计 Mango 等靶标时重训排除与靶标 TM≥0.45 的训练结构；另做 TM≥0.40/0.35 更紧阈值稳健性检验
- **资源**：Zenodo 10.5281/zenodo.20528802（数据）；GitHub sfwang-auto/AlignIF（代码，v1.2/commit 831f857）

### 3. RhoDesign（Nat. Comput. Sci. 2024，Collins/李煜）★ 次推荐
- **数据源**：PDB 3,435 条 + RhoFold 蒸馏 369,499 条（RNAcentral 随机 100 万条序列预测，pLDDT>0.6 过滤）
- **清洗**：真实结构无额外过滤；蒸馏 pLDDT>0.6（>80 反而更差：仅 34,565 条且性能下降）
- **交叉验证**：5 折，序列 PSI-CD-HIT 0.6 + 结构 US-align TM 0.5，80/20
- **泄漏控制**：测试集 276 条，删除与训练集序列相似性>0.6 或 TM>0.2 者；最终 train-test 最大序列相似性 0.514、最大 TM 0.172
- **适配体流程**：以 6UP0 为模板，重训排除相似性>0.5 训练数据；生成过滤 RMSD<7.5Å + 序列相似性<0.65 → 18 候选；第二轮 5,000 采样 → MPBind>0.4 → 1,818 → t-SNE 精选 20
- **复现成本**：RhoFold 推理 100 万条序列较重（可 1/10 子采样验证）；DSSR 需注册授权（学术免费）

### 4. gRNAde（ICLR 2025）
- **数据源**：RNASolo ≤4.0Å，快照 2023-10-31：4,223 序列/12,011 结构/280 万核苷酸（长度 684.9±1072.8 nt）
- **过滤**：<10nt 排除；>1000nt 仅进训练
- **聚类**：US-align TM>0.45
- **划分（单态）**：Das 2010 的 14 条经典 RNA 所在簇全进测试（100 结构样本）；val/test 簇序列数≤5；~4000 训练/100 验证
- **划分（多态）**：序列内中位 RMSD 排序，Top 100 测试、下 100 验证
- **无蒸馏**；HuggingFace 有现成数据集（chaitjo/gRNAde_datasets）可对照
- **对 RDesign 的揭发**：RDesign 划分随机无聚类控制（泄漏风险高），且发布的数据集文件已损坏

### 5. RNAbpFlow（Nat. Methods 2026）
- **数据源**：RNA3DB（2026-04-26 解析）；CASP15 731 条（2022-04 前）；CASP16 994 条（2024-04-06 前）
- **清洗**：排除单原子链；去蛋白残基；只取连续片段；排除无配对链；排除≥20 连续未配对；30–200nt
- **划分**：RNA3DB 官方非冗余 560/48；RNAJP 用 CD-HIT-EST-2D 剔除 2D 冗余
- **蒸馏**：bpRNA-1m(90) 28,370 条 → 30–200nt → MMseqs2 20% 去重 11,048 → 与靶标去冗余 10,107 → ≥10 碱基对 9,289 → AF3 无 MSA 预测 → plDDT≥60 且 PAE≤15 → **2,170 条**；训练 3,164 = 560 实验 + 2,170 蒸馏 + 434 CASP16（实验:蒸馏 1:2.2）
- **配对标注**：训练 RNAView/MC-Annotate/DSSR 三套；推理 IPKnot/SPOT-RNA/RibonanzaNet
- **复现障碍**：AF3 Docker + 三套标注工具 + 8×H100 训练；但**蒸馏管线逻辑（bpRNA→MMseqs2→AF3→置信度过滤）值得照搬**

### 6. RNA-FrameFlow（TMLR 2025）
- **数据源**：RNASolo 2024-01-05，≤4Å 共 14,366 条；取 40–150nt → 5,319 条
- **关键事实**：qTMclust TM≥0.45 → **5,319 条只有 342 个结构簇**——RNA 数据极度冗余的直接证据
- **无划分**（无条件生成，全量训练）；评估用自洽管线（gRNAde→RhoFold，scTM≥0.45）
- **上界分析**：真实结构+RhoFold=55.1%；+逆折叠=43.7%；生成模型=41.0%——瓶颈在工具链
- **裁剪增广教训**：长链随机裁剪 → 多样性↑（0.62→0.88）但有效性暴跌（41%→12%）

## 二、共同模式总结（本项目数据管线的硬性要求）

1. **时间切分**是第一防泄漏手段：训练用旧数据、测试用新释放数据（NA-MPNN、AlignIF、RNAbpFlow、trRosettaRNA2、ODesign 全部采用）
2. **结构聚类按簇划分**：US-align TM-score 0.45 是 RNA 领域公认结构相似阈值（AlignIF、gRNAde）；绝不能按条目随机划分
3. **序列聚类辅助**：核酸 CD-HIT-EST 0.8 / mmseqs2 20%（NA-MPNN、RNAbpFlow）
4. **蒸馏数据必须与训练+测试双重去冗余**（RNAbpFlow 的 MMseqs2 20% 是标准做法）
5. **复合物保守分配**：任一链落测试簇即整个复合物入测试（NA-MPNN）
6. **评估预测器与训练预测器分离**：用 RhoFold 训练就不能用 RhoFold 评估（RhoDesign 的循环论证教训；AlignIF 用 AF3 蒸馏+AF3 评估其实有隐患，其交叉验证用 RhoFold+）
7. **盲测是黄金标准**：CASP15/16（RNAbpFlow、trRosettaRNA2 的最强证据）
8. **报告上界**：报告"ground truth 自洽上界"（RNA-FrameFlow 43.7% 的教训），区分模型误差与预测器误差
9. **多阈值稳健性检验**：AlignIF 的 TM≥0.45/0.40/0.35 三档再评估

## 三、复现选择与理由

**首选 AlignIF 管线**：
- 数据源（BGSU RNA 3D Hub）已验证可下载（NR 列表 2,608 簇/3.0A 已取到）
- 工具全开源：US-align 已装（v20260328）、CD-HIT 已有、qTMclust 可装
- 双时间窗 + 簇级划分 + TM 0.45 三重防泄漏，是最严格范式
- 长度 16–512nt 覆盖适配体/核开关/核酶，与项目任务直接相关
- 有 Zenodo 数据 + GitHub 代码可对照验证复现正确性
- 纯 RNA，无蛋白侧依赖

**复现范围**（先小规模验证管线再全量）：
1. BGSU RNA 3D Hub 完整 RNA-only 列表（含释放日期字段）
2. 清洗：分辨率<4Å、长度 16–512nt
3. 结构聚类：US-align TM 0.45（用 qTMclust 或增量代表比对控制计算量）
4. 簇级划分：399/50/50 + 独立时间窗测试集
5. 与 AlignIF 论文数字对照（7,932 条 / 499 簇 / 划分比例）

**关键计算量预估**：7,932 条全两两 US-align ≈ 3,100 万对不可行；须用 qTMclust（代表结构+LSH 加速）或先 CD-HIT 序列预聚类再结构比对。
