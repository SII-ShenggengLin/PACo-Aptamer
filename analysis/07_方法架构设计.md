# 靶标条件化的 RNA 适配体共设计：方法架构设计（草案）

> 2026-08-14 设计稿，供立项讨论。基于 01 文献调研（真问题 1：结合从未被建模）+ 06 数据摸底（1,065 条可训练复合物）。
> 核心叙事：**从"折叠成什么结构"到"结合什么靶标"——RNA 适配体设计的范式升级**

---

## 一、设计原则（区别于 ODesign 的四条差异）

ODesign 已抢"靶标条件化适配体生成"概念先声（77.95% 模拟成功率），本项目必须在四点上显著超越：

| 维度 | ODesign | 本项目 |
|---|---|---|
| 成功标准 | 几何复现（AF3 重折叠 RMSD<5Å） | **结合代理目标进可微分损失**（界面接触/能量项）+ 负对照特异性 |
| 特异性 | 无负设计 | **脱靶上下文对抗训练**（正负线性组合，ProteinMPNN 多态思想） |
| 构象 | 单构象 | **apo/holo 双构象系综**（诱导契合，gRNAde 多状态 + RNAbpFlow 系综） |
| 评估 | 几何过滤 | **zero-shot 靶标严格协议**：测试配体训练期不可见（配体级隔离）+ 结构簇隔离 |

## 二、总体架构（双模块级联）

```
┌─────────────────────────────────────────────────────┐
│ 输入：靶标原子上下文 {坐标, 元素, 化学环境}           │
│       + 可选 RNA 约束 {配对图, 固定 motif, 长度范围}  │
└──────────────────┬──────────────────────────────────┘
                   ▼
┌─────────────────────────────────────────────────────┐
│ Module A：结合构象生成器（co-fold generator）        │
│ SE(3) 流匹配生成 RNA-靶标共折叠全原子构象            │
│ • RNAbpFlow 式碱基对条件化（L_bp2D/L_bp3D 辅助损失） │
│ • 靶标原子为硬锚点（coordinate 条件），生成 RNA 骨架 │
│ • 多构象采样 → 构象池（trRosettaRNA2 系综思想）      │
│ • 接口接触密度作为可微正则项（结合代理目标 1）       │
└──────────────────┬──────────────────────────────────┘
                   ▼
┌─────────────────────────────────────────────────────┐
│ Module B：结合界面序列设计器（co-design sequence）   │
│ LigandMPNN 三图框架迁移：RNA图 + 靶标图 + 交叉图     │
│ • 碱基节点特征：类型 + 糖环褶皱(C2'/C3'-endo) + χ角  │
│ • 元素 one-hot + 距离/角度几何特征（LigandMPNN 式）  │
│ • 自回归随机顺序解码 + 固定 motif 上下文             │
│ • 界面残基强化：界面掩码加权损失（结合代理目标 2）   │
└──────────────────┬──────────────────────────────────┘
                   ▼
┌─────────────────────────────────────────────────────┐
│ Module C：特异性判别器（负设计）                    │
│ • 正样本：RNA-靶标对；负样本：RNA-非靶标配体对       │
│ • 对比损失（InfoNCE 式）或正负 logit 线性组合        │
│ • 训练中注入"脱靶上下文"（同家族其他配体）           │
└─────────────────────────────────────────────────────┘
```

### 三阶段训练策略（解决数据稀缺）

| 阶段 | 数据 | 目标 | 理由 |
|---|---|---|---|
| S1 自监督预训练 | 纯 RNA 池（6,988 链 + 可选蒸馏） | 学 RNA 折叠语法（配对图、骨架几何、恢复率） | 数据量大 5-6 倍，建立 RNA 先验 |
| S2 复合物微调 | 1,065 条复合物（含配体上下文） | 学"靶标上下文 → RNA 序列/构象"映射 | 核心能力 |
| S3 特异性对抗 | 负样本对（随机配体替换） | 判别器损失 → 特异性 | 负设计落地 |

**预测结构蒸馏扩数据**（RNAbpFlow 先例：2,170 条蒸馏）：
- 候选：AptaDB 1,350 相互作用（有序列无结构）→ AF3 预测复合物 → 置信度过滤（ipTM/pLDDT 阈值）
- 蒸馏数据必须与训练+测试双重去冗余（MMseqs2 20%，RNAbpFlow 标准）

## 三、图网络设计细节（Module B，最核心）

### 三图框架（LigandMPNN 迁移）
1. **RNA 图**：节点 = 碱基（6-原子位姿或 4 原子坐标）；边 = k-NN（10Å）+ 配对边（来自配对矩阵）
   - 节点特征：类型 one-hot(4) + 糖环褶皱 + χ 角正弦余弦 + 主链二面角（8-9 个）
   - 边特征：距离 + 方向（等变坐标几何）
2. **靶标图**：节点 = 配体原子（元素 one-hot + 原子名 one-hot + 杂化/环性）
3. **交叉图**：RNA 碱基 ↔ 靶标原子（<8Å 建边，距离+角度特征）——**结合信息的载体**

### 等变性选择
- 全局 SE(3) 等变（E3NN/GVP 卷积）或：**坐标-特征解耦**（ProteinMPNN 式：编码器吃绝对坐标+相对几何特征，解码输出序列不依赖坐标系）——LigandMPNN 已验证后者在序列设计上更稳、更快
- 建议：Module A 用 SE(3) 等变（坐标生成必须），Module B 用 ProteinMPNN 式（序列设计稳定）

### 关键机制
- **坐标噪声训练**：σ=0.02–0.1Å 是蛋白经验；RNA 预测更不准 → σ=0.05–0.2Å 加大 + 训练时随机旋转（消除晶体学记忆，防泄漏第 6 条）
- **随机顺序自回归**：temperature 采样 + log 概率排序筛选
- **固定 motif**：适配体引物区/保守环可固定（固定节点进上下文）——与 SELEX 引物设计衔接

## 四、结合代理目标（本项目对"结合从未被建模"的直接回应）

三档递进（第一档先落地，后两档逐步增强）：

1. **界面几何目标**（可微，第一版即实现）：
   - 界面接触密度：配体 5.0Å 内 RNA 原子数（NA-MPNN interface mask 逻辑）最大化
   - 界面互补距离惩罚：RNA 原子与配体原子过近(<2.2Å) 冲突惩罚
   - 界面残基恢复率加权：训练时界面残基损失权重 ×2-3
2. **能量代理目标**（第二版）：RNALig/RNAPosers 式打分模型（训练好的 ΔG 预测器）作为可微层？——注意：**用预训练打分模型做损失 = 打分模型与评估预测器的分离问题**，需谨慎（防泄漏第 6 条：评估预测器与训练预测器分离，若用 AF3 评估则不能用 AF3 蒸馏做损失）
3. **对比目标**（第三版）：负样本（同家族异配体）拉低结合打分 → 特异性

**关键原则**：结合代理目标本身不能依赖 AF3/RhoFold+（评估侧预测器），否则循环论证。建议用独立训练的轻量打分器（RNAPosers 式）或纯几何/物理项。

## 五、验证协议（纯计算三支柱，立项文档的核心）

### 支柱 1：zero-shot 靶标严格基准（防泄漏第一）
- **划分**：按配体 ID 隔离测试靶标（测试配体训练期完全不可见）+ RNA 结构簇隔离（TM<0.45 簇级 holdout，CD-HIT 0.8 预聚类）+ 时间切分（训练 ≤ 阈值日期）
- **基准集**：8-10 个零结构、零序列先验的新靶标（从 AptaDB/SPIRAL 挑选，与训练配体化学空间不同的）
- **评估**：模型生成 100-400 候选/靶标 → AF3 复折叠 → 界面指标（ipTM/iPAE/RMSD）→ 成功率（对照 ODesign 77.95% 口径报告，但用严格版本：无长度提示、无 hotspot 提示）

### 支柱 2：双预测器交叉自洽 + 负对照特异性
- **双预测器**：AF3（评估主）与 RhoFold+（交叉验证，对齐 01 文档 43.7% 上界分析）
- **负对照**：同一 RNA 候选 + 替换靶标（随机/同家族）→ 结合保真度应显著下降 → 特异性指标 NCE（负对照效应）
- **自洽上界报告**：ground truth 复合物经同一管线自洽 → 区分模型误差与预测器误差

### 支柱 3：公开功能数据验证（无结构，仅功能）
- **Eterna**：OpenKnot/现有谜题设计序列 → 结构验证数据（gRNAde 路线）
- **AptaDB**：1,230 个 Kd 的适配体序列空间 → 生成序列与已知适配体的相似性/结合位点 motif 命中（功能先验命中率）
- **SELEX 文献**：已知适配体家族序列召回（生成序列能否覆盖已知适配体空间）

## 六、与数据摸底结果的衔接（06 报告）

- 1,065 条可训练复合物：中位 60nt、≤4Å、16-512nt —— Module A/B 训练数据基础
- 配体集中（SAM 50/PAR 44/ATP 53…）：按配体划分的测试集配体数有限 → **测试靶标主要靠 AptaDB 补充**（有序列无结构 → AF3 蒸馏成结构 → 作为 zero-shot 测试靶标）
- 靶标种类 ~50-80 种：S1 自监督（纯 RNA 大池）与 S3 负设计（跨配体对比）缓解多样性不足
- RNA-蛋白（7,331 条目）第二战场：Module A/B 架构天然可迁移（蛋白作为靶标图），立项后作为扩展

### 六-b、靶标图通用性设计（2026-08-14 追加：蛋白靶标可行性演示）

**原则**：靶标图节点类型统一抽象——`TargetNode(元素/残基 one-hot + 化学环境特征 + 坐标)`，小分子用原子节点、蛋白用残基节点（Cα + 侧链代表原子），交叉图建边逻辑不变（<8Å 距离+角度特征）。**从设计上保证"换靶标类型不改架构"**，为论文"蛋白靶标可行性演示"（08 立项文档 8.1）提供实现基础。

具体实现要点：
1. 节点特征：小分子=元素 one-hot + 原子名 one-hot + 杂化/环性；蛋白=残基类型 one-hot + 主链二面角 + 溶剂可及性——统一为 `[类型特征 || 几何特征]` 拼接，MLP 投影到同一维度
2. 交叉图：RNA 碱基 ↔ 靶标节点 <8Å 建边，距离 + 方向特征（两靶标类型共用同一特征器）
3. 结合代理目标不变：接触密度/冲突惩罚按靶标节点统一计算（原子级 vs 残基级均可）
4. 蛋白数据路径（演示用）：7,331 条目适配体语义清洗（排除核糖体/剪接体组成性复合物）+ AptaDB 蛋白适配体 AF3 蒸馏补充

## 七、风险与对策

| 风险 | 对策 |
|---|---|
| 靶标种类少，zero-shot 泛化不成立 | 配体级隔离做训练时即已知；用 AptaDB 扩展靶标空间；如实报告"可泛化靶标化学空间"边界 |
| AF3 对 RNA-配体复合物预测不准（01 报告：RNA-配体 iPTM 仅 0.57） | 双预测器交叉 + 自洽上界报告；指标以"相对负对照"而非绝对值为准 |
| 结合代理目标无效 | 三档递进，第一档几何目标必做；能量代理第二版做消融 |
| 计算资源（AF3 蒸馏 1,350 复合物） | AF3 按需跑（蒸馏 200-400 条足够）；GPU 用 1/2 号 |
| ODesign 抢先发正式版 | 速度优先：3 个月内出基线（S1+S2 纯 RNA 池 + 简单靶标条件化），验证协议本身就是贡献 |
