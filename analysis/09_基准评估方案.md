**防泄漏设计**：
- 结构簇级 holdout：qTMclust TM0.45 + CD-HIT 0.8 预聚类（1,205 簇，6,973 链映射），同一簇不跨集合

- 配体级隔离：zero_shot_targets 的配体（56 种）在训练集 379 种配体中完全不可见
- 巨簇（>15 条目）全部留训练（val/test 被单一折叠主导会失真）

## 二、对比方法清单与开源可用性（已调研 2026-08-14）

### 方法与任务口径分类

| 方法 | 任务口径 | 代码/权重 | 复现成本 | 对我们数据的适配 |
|---|---|---|---|---|
| **gRNAde** | 结构→序列（逆折叠） | GitHub chaitjo/geometric-rna-design；权重 v0.3.2（ICLR2025）/v1.0.0（bioRxiv）；数据 HuggingFace chaitjo/gRNAde_datasets | 低（预训练权重直接用） | 输入 RNA 结构输出序列——可直接在我们测试条目上跑 |
| **RhoDesign** | 结构→序列（逆折叠，RhoFold 蒸馏训练） | GitHub ml4bio/RhoDesign（MIT）；checkpoint Google Drive；含 eval_model.py | 低-中 | 同上；**注意其训练含 RhoFold 蒸馏——评估预测器须分离** |
| **RNA-FrameFlow** | 无条件生成骨架（40-150nt） | GitHub rish-16/rna-backbone-design；camera_ready_ckpts 预训练权重 | 低（权重）+环境（e3nn/flash-attn） | 只能做无条件生成有效性评估（自洽 TM），不是逆折叠 |
| **RNAbpFlow** | 序列+碱基对→结构（条件生成） | GitHub Bhattacharya-Lab/RNAbpFlow（2026-01 更新） | 中（需三套配对标注工具 + 权重待确认） | 碱基对条件生成→可评估"给定天然碱基对能还原结构吗" |
| **ODesign** | 靶标→RNA（靶标条件化！与我们最直接对比） | GitHub OTeam-AI4S/ODesign（Apache 2.0）+ ODesign-pipeline；模型参数开源 | 中-高（大模型，推理需 GPU） | 输入靶标坐标+长度 → 生成 RNA → 与我们方法同口径对比 |
| **AlignIF** | 结构→序列（MStA 多结构比对） | GitHub sfwang-auto/AlignIF；Zenodo 数据本地已有 | 中（训练需官方数据） | 同 gRNAde 口径；独立测试集设计 Mango 等靶标重训排除 |
| **NA-MPNN** | 结构→序列（统一聚合物） | Baker lab 开源；蒸馏数据 TRANSFAC 不可分发 | 中（训练数据缺 72%） | 只能评估其预训练能力；RNA 单体 63 条训练太薄，**降优先级** |
| trRosettaRNA2 | 结构预测（非生成） | Nat Mach Intell 2026；服务器 | — | 用作**评估预测器**候选（非对比方法） |

### 评估分层策略（解决训练数据重叠的泄漏问题）

对比方法的预训练权重大多包含 2023 前的实验结构（含我们的 train/val/test 条目）——**只有 independent_test（2024+）对这些方法无泄漏**。因此：

- **A 层（快速公平对比）**：官方预训练权重 × independent_test（95 条目）——时间隔离保证公平，一周内出全方法性能
- **B 层（重训对比）**：对关键方法（gRNAde、RhoDesign）用我们的 train 划分重训，val 做模型选择，test 评估——完全公平，**与 A 层交叉验证**；重训权重保存复用
- **C 层（zero-shot 专项）**：ODesign × zero_shot_targets（85 条目）——靶标条件化同口径对比；我们的方法也在此评估
- **上界对照**：ground truth 自洽（真实结构→预测→TM）与 4 字母随机基线（25% 恢复率）全程报告

## 三、指标清单（对比方法性能的核心交付）

### 指标 × 任务类型矩阵

| 指标 | 定义 | 逆折叠方法（gRNAde/RhoDesign/AlignIF/我们的） | 生成方法（FrameFlow/RNAbpFlow/ODesign） |
|---|---|---|---|
| **序列恢复率** | 设计序列 vs 天然序列同位置匹配率（4 字母基线 25%） | ✅ | 部分（有序列输出的） |
| **结构保真 scTM** | 设计序列→RhoFold+ 预测结构→US-align TM vs 天然结构（≥0.45 有效） | ✅ | ✅（生成结构直接对天然） |
| **二级结构一致性** | RNAfold 预测 SS vs 天然 SS（RNAView/DSSR）的配对 F1 | ✅ | ✅ |
| **界面口袋恢复率** | 配体 5.0Å 内 RNA 残基的序列恢复（结合相关的核心新指标） | ✅ | ✅ |
| **界面接触保留率** | 设计序列预测结构中，配体 5.0Å 内 RNA 残基数 / 天然界面残基数 | ✅ | ✅ |
| **AF3 复折叠界面保真** | 设计复合物→AF3 复折叠→ipTM/界面 RMSD（**评估预测器**） | ✅（抽样子集，成本高） | ✅ |
| **负对照特异性** | 同一设计 + 替换靶标（随机/同家族）→ 结合保真下降幅度 | 靶标条件化方法 | 靶标条件化方法 |
| **自洽 TM** | 生成结构→逆折叠→预测→TM（RNA-FrameFlow 43.7% 上界口径） | — | ✅ |
| **生成有效性** | 结构有效性（无冲突/化学合理）/ 构象多样性 | — | ✅ |
| **计算效率** | 每序列生成耗时（GPU 1/2 号记录） | ✅ | ✅ |
| **恢复率-功能相关性** | 恢复率与 Kd（AptaDB）的 Spearman 相关 | ✅（有 Kd 的子集） | — |

### 指标定义细节（防口径争议）

1. **恢复率**：同位置 4 字母匹配；修饰核苷酸归一化到母碱基（2MG→G）；缺口跳过——对齐 gRNAde 口径
2. **scTM**：RhoFold+ 预测（**评估预测器，与任何训练侧预测器分离**，防泄漏第 6 条）→ US-align vs 天然；多构象取 max
3. **界面**：配体重原子 5.0Å 内 RNA 残基（与摸底/界面标注口径一致）
4. **AF3 复折叠**：substrate 模式，设计序列 + 靶标 → 复折叠复合物 → 界面 ipTM/iPAE；**样本量 30-50/方法**（成本控制），随机种子固定
5. **负对照**：靶标替换为训练集中同化学空间异配体 → Δ(结合指标) < 0 且显著

## 四、模型权重管理策略（用户明确要求）

1. **训练检查点**：每轮结束存 `ckpt/last.pt` + 按 val 指标存 `best_val.pt`（早停后保留 best + last 两个）
2. **统一目录**：`models/{method}/`，命名含 日期_数据版本_划分版本（如 `20260814_v1_s1.pt`）；训练脚本记录完整 config（seed/数据路径/划分文件 hash）到 ckpt 内
3. **wandb 归档**：本地 wandb 已装；每方法一个 project，artifact 存权重（防磁盘丢失）
4. **对比方法权重**：官方 checkpoint 一律复制到 `models/{method}/official/` 并记录下载 URL 与 commit hash（可复现）
5. **结果缓存**：所有评估结果存 `results/{method}_{split}.json` + 指标计算脚本入 data/ 编号脚本序列，可重跑

## 五、执行计划（下一步，按优先级）

1. **评估基础设施**：装 torch_geometric/e3nn/ViennaRNA；部署 RhoFold+（RhoDesign checkpoint）；确认 AF3 可用路径
2. **A 层评估**：gRNAde（官方权重）→ RhoDesign → RNA-FrameFlow/RNAbpFlow（生成类）→ ODesign（zero_shot 子集），全部在 independent_test 上
3. **界面标注管线**：配体 5.0Å 口袋标注 → 界面恢复率/接触保留率两个核心指标可计算（所有方法通用）
4. **B 层重训**：gRNAde 用我们划分重训（torch_geometric 装好后）→ 与 A 层对照验证时间切分有效性
5. **指标报告初版**：所有方法 × 所有指标的表格 + 每个方法"特点与不足"定性分析（用户需求：借对比理解各方法）
6. 之后才进入我们自己的方法设计（08 立项文档架构做参考，不锁定）

## 六、风险与说明

- **ODesign 推理成本**：大模型，zero_shot 85 条目 × 400 候选不现实 → 每靶标 50-100 候选，GPU 1/2 号
- **RNAbpFlow 权重待确认**：仓库 2026-01 更新，若权重不全则降级为"代码复现 + 小规模训练"
- **A 层公平性声明**：independent_test 对官方权重无泄漏（时间隔离），但**注意 2024 年释放的条目其结构可能在更早论文预印本/服务器中出现**——如实报告此残留风险
- **B 层是最终裁定**：重训对比是最干净口径，论文主表用 B 层结果，A 层作补充
