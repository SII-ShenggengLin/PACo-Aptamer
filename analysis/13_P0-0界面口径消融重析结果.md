# P0-0 界面口径消融重析：结果与决策记录

> 日期：2026-08-18。脚本：`data/74_p00_iface_ablation.py`；产物：`survey/74_iface_meta.json`（界面元数据）、`survey/74_pools/*.json`（5 ckpt 序列池）、`survey/74_ligand/*.json`（2 ckpt × 3 条件）、`survey/74_p00_iface_ablation.json`（汇总）。
> 动机：蓝图 `12_NatureMethods写作与实验设计蓝图.md` §3.1——配体/界面模块在全局恢复率口径下消融噪声级（-0.84/-1.00pp），但界面仅占序列 2-3% 位点，全局指标物理上看不见界面效应；需用界面口径重判模块去留。

## 一、实验设计

- **口径**：38 号同款 quick 诊断口径（10 样本/温度 × 3 温度 = 30 池，splits_v2 test 477 链，native = taco_s1_v2 缓存）。管线复现校验通过：
  | ckpt | 旧表（10 号报告 7.2） | 本次重跑 |
  |---|---|---|
  | baseline s2_v2 | 64.66 / 56.85 | 64.59 / 56.82 |
  | no_ss | 61.38 / 53.28 | 61.35 / 53.29 |
  | no_ligand | 63.82 / 56.99 | 64.11 / 56.95 |
  | no_iface | 63.66 / 56.22 | 63.58 / 56.22 |
  | no_aug | 64.30 / 57.32 | 64.49 / 57.31 |
- **界面定义**：35 号训练同款（功能配体 605 种 CCD，残基原子与配体原子 <5Å）——与 no_iface 消融的训练语义一致，是判断模块是否起效的正确口径。**与论文 64 号界面表口径（eval_inputs_v2，45 链、多为 1-2 残基）不同**，论文呈现时需统一。
- **界面链规模**：功能配体链 159 / 477；界面链 118（**96 条界面 ≥6 残基**——比 64 号口径大得多，统计功效充足）；剔除异常链（1EI2_A 等界面 >50 残基的拼接假序列链）后 115 条，≥3 残基子集 100 条。
- **Phase 2（推理期配体）**：115 界面链 × 3 条件（空配体 / 真实配体 / 错配配体[异条目坐标+当前 C1' 重算 RBF]）× 30 池；baseline 与 no_ligand（安慰剂对照）双模型。
- **统计**：池内 best 口径（界面/整体独立取 max，64 号惯例）；bootstrap 95% CI（1000 次）；配对单侧 Wilcoxon。
- 修复记录：①配体 RBF 的 C1' 需恢复 FILL 语义（coords9 的 NaN 会污染特征，曾致 2XO0/2XO1 崩溃）；②采样加 try/except 护栏（no_aug 权重存在链相关的偶发 NaN logits，本次运行未触发）。

## 二、结果

### Phase 1：界面口径消融（115 界面链）

| ckpt | 全局 best(477) | 界面 best | 子集整体 best | Δ(界面-整体) | ≥3残基子集 Δ | vs baseline 界面差（Wilcoxon 单侧 p） |
|---|---|---|---|---|---|---|
| **baseline** | 64.59 | **68.36** | 66.53 | +1.83 | -2.18 | — |
| no_ligand | 64.11 | 65.18 | 66.65 | **-1.46** | **-5.65**（CI -9.3~-2.6） | **+3.17pp（p=0.0060）** |
| no_iface | 63.58 | 69.50 | 66.71 | +2.79 | +1.76 | -1.15（p=0.94，不显著） |
| no_ss | 61.35 | 70.09 | 63.81 | +6.29 | +1.82 | -1.74（p=0.82，不显著） |
| no_aug | 64.49 | **73.39** | 66.13 | **+7.26** | +3.54 | -5.03（即 no_aug 界面更高） |

**核心读数**：
1. **配体模块（no_ligand）在界面口径显著起效**：去掉后界面恢复率掉 3.17pp（p=0.006）；≥3 残基子集上界面-整体差从 baseline 的 -2.18pp 恶化到 -5.65pp（CI 不含 0）。**全局 -0.5pp 的"噪声级"恰是界面 +3pp 效应被 2-3% 位点占比稀释的算术预期**——蓝图 3.1 的预测被证实。
2. **界面加权（no_iface）证据不足**：界面口径差异 -1.15pp 不显著（p=0.94）。作为损失加权它不改变推理信息流，未带来可检出的界面增益。
3. no_ss 的界面恢复 ≈ baseline（70.1 vs 68.4）——界面残基由口袋几何决定，SS 主要帮助非界面区；SS 的全局杠杆（-3.2pp）与配体的界面杠杆（-3.2pp 界面）**作用位置互补**。
4. 意外观察：no_aug 界面恢复反而最高（73.4，比 baseline +5pp）——坐标噪声 σ=0.1Å 可能钝化口袋几何精度（增益全局鲁棒、损失界面锐度）。quick 口径下的观察，正式版需 300 池复核。

### Phase 2：推理期配体（115 链 × 3 条件）

| 模型 | 条件 | 界面 best | 整体 best |
|---|---|---|---|
| baseline | 空 | 68.76 | 66.99 |
| baseline | 真实配体 | 69.80 | 67.05 |
| baseline | 错配配体 | 69.27 | 67.17 |
| no_ligand | 空 | 66.38 | 66.69 |
| no_ligand | 真实配体 | **59.82** | **51.12**（崩溃） |
| no_ligand | 错配配体 | 60.20 | 52.57（崩溃） |

- baseline：真实 vs 空 +1.04pp（CI -1.1~+3.1，p=0.16）；真实 vs 错配 +0.53pp（n.s.）——**RNA 结构已给定时，推理期配体的边际信息量小**（结构本身已确定大部分界面身份）。
- no_ligand 安慰剂：喂任何配体都崩溃（整体 -15.6pp）——**证明 baseline 的配体 token 确实被整合进表示**（对照成功，Phase 2 机制无 bug）。

## 三、决策（回应"要不要删模块"）

1. **配体上下文模块：保留**。界面口径显著有效（p=0.006），是真实起效的模块；论文消融表应报告**全局+界面双口径**，no_ligand 行"全局噪声级 / 界面显著"的组合本身就是"评估指标错位"的论证素材，直接支撑"从折叠到结合"叙事（蓝图版本 B 的第一块基石成立）。
2. **界面加权模块：从创新点清单移除**（降级为训练细节，如实报告无独立界面增益；是否物理移除留待正式口径复核——本次 quick 口径下全局方向仍有 +1.0pp）。论文不再把"界面加权"当方法学卖点。
3. **Phase 2 的叙事定位**：推理期配体在"结构已知"的恢复率任务中边际小是合理的（不是失败）——配体条件化的价值场景是 zero-shot 靶标辨别与从头设计；这提示后续实验（蓝图 P0-1 条件跟随性）应把"同结构不同配体"的辨别任务作为配体敏感性的主战场，而非恢复率。
4. **升级待办**：正式版用主配置（ens2/seed43）+ 300 池 + 统一界面口径（与 64 号论文口径对齐或明确两套口径的用途）复核本结论；no_aug 的界面 trade-off 值得顺带复核（可能成为一个分析点）。

## 五、P0-0b：界面加权删除的正式口径验证（2026-08-18 追加）

用户追问：界面加权还有必要留在模型里吗？→ 在主配置家族（seed43）上做删除验证。

**实验**：统一 S2 配方（joint + val_sel + batch4 + 8 epoch，init = s1_batch4_seed43.pth）重训无界面加权版（`s2_v2_seed43_noiface.pth`，4 分钟）；两个模型同管线 300 池 B 层评估（manifest 口径，管线校验：seed43 含加权版 71.50/60.07 ≈ 9.1 记录的 71.49/60.07）。

| 模型（300 池，manifest） | 全局 best/t01 | 界面 best | Δ(界面-整体) |
|---|---|---|---|
| seed43（含界面加权） | 71.50 / 60.07 | 83.11 | +11.19 |
| seed43-noiface（删除） | 71.36 / 59.68 | 82.24 | +10.18 |
| **删除代价** | **-0.14 / -0.39pp（评估噪声内**，历史同 ckpt 双评估 Δ0.17-0.34pp**）** | -0.87pp（不显著；对照配体模块 +3.17pp/p=0.006） | — |

**结论：界面加权正式删除**。quick 口径曾见的 -1.0pp 全局效应在正式口径下消失（亦是噪声）。S2 级 noiface ckpt 已备好：`s2_v2_seed43_noiface.pth`、`s2_v2_ssdo15_noiface.pth`（ssdo15 同配方已训），ens2-noiface 主配置重建 = 39 号集成评估 + 63/69 号表格重算，一条命令量级。

**对论文的影响**：
1. 方法描述中"结合代理目标第一档"不再包含界面损失加权——如实定位为**纯条件化方法**（配体原子上下文 + SS），这本来就是比损失加权更强的结合建模方式，P0-0 的界面显著性证明的正是条件化本身。
2. 消融表收敛为三行且行行显著：no_ss（全局 -3.2pp）/ no_ligand（界面 -3.2pp，p=0.006）/ 集成——每个保留组件都有证据，无"零效组件"授人以柄。
3. 论文解决的问题与方法创新性不受影响（详见蓝图 §3.2：问题=结合未被建模→配体条件化；创新=条件化+协议+基准）。
