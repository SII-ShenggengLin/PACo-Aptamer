# P1-1 AptaDB 回顾性验证结果（Fig6d"计算版湿实验"）——诚实阴性 + 机制

> 产出：2026-08-18。执行蓝图 §五 P1-1（"无湿实验论文最重要的功能侧证据"）。
> 管线：`data/78_aptadb_crawl.py`（爬取/解析）+ `data/79_aptadb_retro.py`（清洗/泄漏核查/RhoFold+ 批预测/打分/报告）+ `data/80_aptadb_diag.py`（机制诊断 D1-D4）。
> 数据：`survey/78_raw/`（1,350 页原始 HTML）、`survey/78_aptadb.json`、`survey/79_aptadb_clean.json`、`survey/79_rhofold/`（254 结构）、`survey/79_aptadb_scored.json`、`survey/79_aptadb_retro.json`、`survey/80_diag.json`。
> **结论速览：原计划的"Kd 回顾性 enrichment"不成立（家族内相关/最优排名/合并分层全部 n.s.），且发现一个更有价值的系统性现象——真实 SELEX 适配体在结构条件逆折叠模型似然下系统性低于随机序列（仅 ~10% 反超）。三个诊断排除计算假象后，该结果稳健，恰好构成"恢复率≠结合、评估需要结合口径"主线的外部实证。Fig6d 按用户/叙事纪律降级为"回顾性审计"呈现或移除。**

## 一、数据与管线

### 1.1 AptaDB 获取（78 号）
- 官网（lmmd.ecust.edu.cn/aptadb，RNA 2024 30(3):189）无批量下载 → 礼貌爬取 `result.php?id=1..1360`，0.25s 限速，~22 分钟。
- **1,350/1,350 交互全量获取**（10 个越界 id 失败=库边界，无真损失）。逐条解析：序列/RNA-DNA 化学类型/靶标 uid+类型/affinity 原文/assay/PubMed ID/RNAfold SS。
- 全库构成：RNA 283 / DNA 1,067；靶标 Protein 639 / Molecule 393 / Cell 189 / Other 129；affinity 可解析 ~1,228（nM 962 / μM 215 / pM 33 / mM 15 / M 3）。

### 1.2 清洗与泄漏核查（79 号 clean/leak 相位）
- RNA-only（模型是 RNA 字母表；DNA 全部剔除并在论文注明）、ACGU 合法、长度 15-300、(序列,靶标) 去重 → **254 条唯一交互 / 139 靶标**（22 个 ≥3 Kd 家族、41 个 ≥2）。
- **泄漏核查（cd-hit-est 0.8 与本项目全序列库联聚类）**：3 条与训练集精确同序列、40 条与训练序列同簇 → **主分析用干净集 214 条**，254 全量为敏感性口径。
- RhoFold+ 单序列模式预测全部 254 条结构（GPU 1/2 并行 24 分钟，**254/254 零失败**）；coords9 转换按 TACO9 九原子（嘌呤 N9→N1 槽位，与训练 featurization 一致）。
- 打分：ens2 主配置（seed43+ssdo15 概率平均）teacher-forced mean logP。每条适配体三个条件：
  - **self**：自身序列 + 自身预测结构 + RNAfold(自身) SS
  - **randA**：随机序列（同长度均匀 ACGU×10）+ **同一结构与同一 SS**——隔离出纯序列效应
  - **randB**：随机序列 + 同结构 + 各自 RNAfold SS

## 二、主结果（254 打分 / 214 干净集）

### 2.1 (a) 序列先验：真实适配体低于随机序列 ✗（反直觉但稳健）

| 口径 | 数值 |
|---|---|
| logP(适配体) − logP(randA) | **−0.56 log 单位**（CI −0.61~−0.50，序列均值差） |
| 适配体反超随机对照的比例 | **9.8%**（214 干净集 10.0%） |
| 每核苷酸 logP：适配体 vs 随机 | −0.062 vs −0.052 |

randA 与适配体**共享同一结构、同一 SS、同一长度**，唯一差异是序列本身——随机序列胜出是纯序列效应。

### 2.2 (b-d) Kd 回顾性：全部不显著 ✗

| 分析 | 结果 |
|---|---|
| (b) 家族内 Spearman(logP, −log10 Kd)，19 家族 | mean ρ=0.10（CI −0.19~0.40），58% 正向 |
| (c) 最优 Kd 适配体的模型排名百分位 | 0.443（CI 0.28~0.61），p(单侧<0.5)=0.999 |
| (d) 家族内 z 标准化合并（n=84 设计对） | ρ=0.13，top 四分位 −log10Kd 优势 +0.40 SD |
| (e) top-50% 筛选灵敏度（10 家族，探索性） | 0.633（CI 0.42~0.83，p=0.002） |

(e) 名义显著但仅 10 家族且与 (b)(c)(d) 不一致，按多重检验纪律记为**未确认的探索性信号**，不作主张。

**判定：gRNAde 图6 式的"模型置信度回顾性富集功能"在本模型上不成立。Fig6d 原计划作废。**

## 三、机制诊断（80 号，排除计算假象 + 定位成因）

| 诊断 | 结果 | 排除/确立 |
|---|---|---|
| **D1** 同一 PDB 天然序列：实验结构 vs RhoFold 预测结构下打分（21 链） | 实验 −0.021/nt vs 预测 −0.074/nt（**实验高 +0.054/nt**，CI 0.048-0.059） | 排除"预测结构抬高随机分"——预测结构反而压低所有人分数；(a) 的排序若换实验结构只会更显著 |
| **D2** 随机序列：自身预测结构 vs 借用适配体结构（30 对，长度匹配） | 自身 −0.065/nt vs 借用 −0.054/nt | 排除"随机分高是借了适配体量身结构"——借用结构确实略有利，但量级不足以解释 (a) |
| **D3** 组成效应（254 条） | 适配体 GC 均值 0.54；ρ(GC,logP)=−0.116；GC 0.5-0.6 箱最优 −0.055、0.7-0.8 箱 −0.090 | 组成解释一部分（随机序列恰好落在模型先验的最优组成区） |
| **D4** G-四链体分层（214 条） | G4+（32 条）亏空 −0.486 vs G4−（182 条）−0.597，MW p=0.96 | 排除"亏空=G4 伪影"——off-manifold 效应对 SELEX 适配体普遍成立 |

**机制结论**：似然的层级由两件事决定——① 结构质量（实验结构 ≫ 预测结构，+0.05/nt）；② 序列与"PDB 天然折叠 RNA 流形"的距离。SELEX 适配体（为结合而选择、组成偏置、常不折叠成典型结构）在 ② 上系统性偏离：**给定完全相同的结构条件，结合选择的序列输给均匀随机序列**。这不是 bug 而是领域级现象：**恢复率/似然类指标度量的是"像天然结构 RNA"，不是"是适配体"**。

## 五、限制（报告与论文都须写明）

- AptaDB 无结构 → 全部用 RhoFold+ 预测结构（D1 显示预测结构压低所有人 logP ~0.05/nt；家族内分析同受此噪声影响，但 (a) 的对照设计使结论对结构质量不敏感）。
- Kd 跨实验室/assay，家族内比较已最小化该影响，但家族数少（19）功效有限。
- RNA-only（DNA 1,067 条未测）；小分子/蛋白/细胞靶标混合。
- 40/254 与训练集同簇条目已在主分析剔除（敏感性口径结论不变）。

## 六、坑位记录（本会话新增）

1. **AptaDB 无批量下载/API**：result.php?id=N 全量爬取可行（1,350 页，0.25s 限速 ~22 分钟）；aptamer 化学类型字段名是 "Aptamer chemistry" 不是 "Chemistry"。
2. **cd-hit-est 的 .clstr 输出文件名 = -o 参数 + .clstr 后缀**（不是独立 -o）。
3. **79 号 fold 首版 (seq,key) 解包顺序写反**：uniq 映射 seq→key，items() 给出 (seq,key)——tmp 目录按序列命名暴露了 bug。父进程 kill 后 RhoFold 孤儿子进程会继续写文件（重跑前要清）。
4. **CUDA_VISIBLE_DEVICES 限制后设备号从 0 数**：子进程 RhoFold 也要 cuda:0（80 号 D2 首版用 cuda:1 静默崩，tmp 目录只有 log.txt 一处可见线索）。
5. **pkill -f 会误伤当前 shell**（交接文档旧坑再现）：命令行里含目标字符串时整条 Bash 调用被杀——用精确 PID 或先 ps 再 kill。
6. **dict 映射方向写在注释里**（`uniq 映射 seq → key`）比事后 debug 便宜。
