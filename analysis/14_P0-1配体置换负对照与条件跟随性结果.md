## 一、实验设计（相对 P0-0 Phase 2 的三处关键升级）

1. **口袋叠合置换**。P0-0 的错配配体用供体原始坐标（PDB 坐标系不同 → 配体常在几十 Å 外，等效"远处配体≈空配体"）。本次用家族内 C1' Kabsch 叠合把供体配体**移植进当前口袋**：移植质量中位质心偏移 0.85Å（p90 2.25）、叠合 C1' RMSD 中位 1.08Å——真正的"同口袋不同化学"counterfactual。
2. **同结构多配体家族发现**（主战场素材）。结构感知聚类：NW 全局对齐（difflib 对应噪声大且不对称，add↔xpt 两方向 RMSD 3.8/6.4Å；NW 后 2.06Å）+ 匹配位 C1' Kabsch RMSD 两档边（≤2.5 或 ≤4.5 且 n≥30；异家族实测 ≥6Å）。**12 个多配体家族 / 130 链 / 41 种 CCD 化学**，覆盖 test + indep/zs：
   | 家族 | 链数 | 配体化学（CCD 组合数） | split |
   |---|---|---|---|
   | 嘌呤核糖开关超家族 | 50 | 21（ADE/6AP/29G/29H/5AZ/2BP/3AW/3AY…嘧啶变体、GUN/HPA/XAN/6GO/6GU/DX4/A2F/CMG/N6M/Q44/ZZR/ZZS…） | test+av2 |
   | 茶碱适配体 | 13 | 5（TEP/QIJ/QB3/QAX/QEU） | test+av2 |
   | 8HZ 荧光适配体 | 12 | 4（O2I/NI4/NJL/O00） | av2 |
   | Mango-III | 11 | 6（HZG/EKJ/HZD/YO3/OXV/W6F） | test+av2 |
   | 黄嘌呤核糖开关 | 9 | 3（XAN/AZA/141） | av2 |
   | ZTP 核糖开关 | 8 | 3（AMZ/UG1/UG4） | test+av2 |
   | 叶酸核糖开关（THF-II+folE） | 8 | 7（THG/DHF/H4B/NPR/GUN/AZG/ANG） | av2 |
   | dG 核糖开关、rhobast、fam_1MMS、fam_3GCA、fam_8HB1 | 4/3/5/4/3 | 2-3 | 混合 |
3. **多对照体系 + 双探针**。条件 grid：`true`（自身配体）/ `geo`（**同化学异条目**叠合移植——安放噪声对照）/ `swap×≤4`（异化学移植，扰动谱选择：最优拟合+最大扰动+分位，保证化学跨度）/ `none`（空配体）。探针：①teacher-forced 逐位 logP(native)（无采样噪声）；②集成采样（嘌呤 100/温度 × 3 温度，其余 30/温度；ens2-noiface 主配置 + seed43 单模 + no_ligand 安慰剂）。
   - 安慰剂效验（管线无泄漏）：no_ligand 模型喂任何配体即崩（整体 t01 −7.5pp、U↔C 位 P(native) −4pp p=0.013）——与 P0-0 一致。
   - geo 对照干净：主模型 true−geo 界面 ΔlogP ≈ +0.0002（n.s.）、恢复率 Δ≈0——**效应不是叠合安放噪声的伪影**。

特异性位点定义（E3 核心量）：家族内 NW 对齐后，**界面内 native 与供体 native 错配的同源位**——即"如果配体换成供体化学、序列应当跟着变"的位点。嘌呤家族中 U↔C 互换位即经典 U74/C74 型特异性决定位（1Y26 索引 61 位；add 亚族 U 配对腺嘌呤、xpt 亚族 C 配对鸟嘌呤，文献中单点突变即可翻转配体特异性）。

## 二、结果

### E1 teacher-forced 似然（ΔlogP(native)，正 = 真配体下 native 更可能）

| 模型 | 界面 true−none | 界面 true−geo | 界面 true−swap | **特异位点 true−swap** |
|---|---|---|---|---|
| ens2-noiface（主配置） | +0.0009（p=.017，量级≈0） | +0.0002 n.s. | −0.0013 n.s. | −0.0031（p=.56） |
| seed43-noiface（单模） | **+0.054（p=2×10⁻⁷）** | +0.0029 n.s. | −0.0011 n.s. | **+0.0068（p=.035）** |
| no_ligand（安慰剂） | −0.95（崩溃）✓ | +0.007 n.s. | +0.024 n.s. | −0.31（负向）✓ |

### E2 界面恢复率（采样，池内 best / t01 双口径）

| 对比 | 全家族 n=120-130 | 嘌呤家族 n=50 |
|---|---|---|
| true − none（口袋占据） | iface_best +0.88pp n.s.；t01 +0.16pp n.s. | iface_best +2.12pp（p=.09）；**t01 +0.95pp（CI 0.5~1.5，p=4×10⁻⁴）** |
| true − geo（安放噪声对照） | +0.95pp n.s. | +1.35pp n.s. |
| true − swap（**化学置换**） | iface_best +0.26pp n.s.；t01 +0.05pp n.s. | iface_best +1.38pp（p=.026）但 t01 −0.10pp n.s.（best 口径不稳定） |

### E3 条件跟随性（生成分布在特异性位点是否跟随配体化学）

- **ens2 主配置：不跟随**。全温度段 ΔP(native@spec) ∈ [−0.006, +0.003] 均 n.s.（t=1.0 边缘 donor +0.7pp p=.047）；**U↔C 位 P(native) 0.498（真配体）vs 0.499（错配）——精确为零**。模型在特异位点输出 U/C 各半（结构知道"嘧啶"，配体不决定"哪个嘧啶"）。
- seed43 单模：微弱但一致的跟随信号——U↔C 位 P(native) −0.40pp（p=.021）/P(donor) +0.39pp（p=.021）；t=0.5/1.0 段 ΔP(native) −0.55~−0.80pp（p≤.027）。**量级可忽略且被集成平均洗掉**。
- 安慰剂：喂任何配体 → 特异位点随机化（P(native) −4pp），非跟随 ✓。

### 与 P0-0 的合并图景

| 证据 | 读数 | 含义 |
|---|---|---|
| 训练期消融（no_ligand 重训） | 界面 −3.17pp（p=.006，P0-0） | 配体条件化**在训练期真实起效** |
| 推理期口袋占据（true vs none） | 嘌呤家族 t01 +0.95pp（p=4×10⁻⁴） | 推理期读到"口袋被占据 + 几何" |
| 推理期化学辨识（true vs swap） | 全口径 ≈0（唯一显著的 best 口径不稳定） | **推理期读不到配体化学** |
| 特异位点跟随（U74/C74 型） | ens2 精确为零；单模 ±0.4pp | 生成分布不随化学条件移动 |

## 三、机制诊断（为什么会这样）

1. **特征瓶颈**：配体 token = 元素 one-hot(5) + 到最近 C1' 距离 RBF(16)。腺嘌呤 vs 鸟嘌呤 = 10 个重原子中 ~2 个原子（6 位 N↔O + 2 位 NH₂↔O）的差别；两配体占据同一口袋时**大多数原子的元素和距离特征完全相同**，化学差异信号在入口处就只剩 1-2 个 token 的元素位差异，经 encoder 进一步稀释。
2. **监督瓶颈**：训练只见过"一个口袋配一个正确配体"，从未被要求做辨别——结构本身已把界面身份确定到 U/C 二选一（P0-0 结论），损失函数里没有任何项奖励"读对化学"。单模残留的微弱信号（+0.4pp）说明梯度里确实有一点化学信息，但既弱又不稳定。
3. 集成平均进一步抹平单模的边缘信号（ens2 对 seed43 的关系在 E1/E3 两探针上一致）。

实现要点（复现必读）：①load_s1 命中缓存时不过滤 subset，meta 相位必须按 split 键遍历；②NW 对齐需返回**全部对齐列**（含错配）——特异性位点恰是错配位，恒等位只够做叠合锚；③difflib 对应不可用于结构叠合（不对称 + 块贪心噪声）；④av2 链特征来自 m68.build_feature（grnade_inputs_v2 坐标系与 rcsb_pdb 一致已验证）；⑤score 相位有输出缓存，grid 变更后需删旧文件。
