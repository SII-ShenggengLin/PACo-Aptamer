## 一、项目定位

### 核心命题（一句话）
**RNA 适配体设计的"最后一环"从未被建模：所有现有方法优化"折叠"，没有方法优化"结合"。本项目构建以靶标分子为条件的 RNA 适配体共设计模型，把"结合什么靶标"纳入可微分目标，并建立纯计算验证协议。**

### 领域现状与竞争格局（2026-08）
- **真问题**（01 报告）：RhoDesign 活性适配体全靠 G-四链体混杂基序（无特异性）；AlignIF 湿实验证明"结构保真 ≠ 结合亲和"（Kd 变差）；所有方法的评估与功能脱节（RNA-配体 iPTM 仅 0.57）
- **竞争**：ODesign（预印本）已抢"靶标条件化"概念先声但零湿实验、成功标准是几何复现；RNAbpFlow 已发 Nature Methods（碱基对条件生成）；LigandMPNN 已发 Nature Methods（配体上下文，框架可迁移）
- **本项目差异化**：① 结合代理目标进可微分损失（非几何复现）；② 负设计/特异性（脱靶对抗）；③ 构象系综；④ **zero-shot 靶标严格评估协议**（配体级隔离——ODesign 未做）

## 三、方法架构（07 草案，要点摘要）

### 总体：双模块级联 + 三阶段训练
```
靶标原子上下文 ──► Module A: 结合构象生成器（SE(3) 流匹配, RNAbpFlow 式碱基对条件化）
                     │        多构象采样 → 构象池 + 界面接触密度可微正则
                     ▼
                  Module B: 结合界面序列设计器（LigandMPNN 三图框架迁移）
                     │        RNA图 + 靶标图 + 交叉图；碱基节点含糖环褶皱/χ角特征
                     │        随机顺序自回归 + 固定 motif + 界面加权损失
                     ▼
                  Module C: 特异性判别器（负设计：InfoNCE 对比 + 脱靶上下文注入）
```

三阶段训练（解决数据稀缺）：
- S1 自监督预训练：纯 RNA 池 6,988 链（学折叠语法，数据量 5-6 倍）
- S2 复合物微调：868 复合物（学"靶标上下文 → RNA 序列/构象"）
- S3 特异性对抗：负样本对（同家族异配体）
- 扩数据：AptaDB 序列 → AF3 蒸馏（RNAbpFlow 先例 2,170 条；**蒸馏数据与训练+测试双重去冗余**，MMseqs2 20%）

### 结合代理目标（对"结合从未被建模"的直接回应，三档递进）
1. 界面几何目标（可微，第一版）：接触密度最大化 + 空间冲突惩罚 + 界面残基损失加权 ×2-3
2. 能量代理（第二版）：独立轻量打分器（RNAPosers 式）——**不能与评估预测器同源**（防泄漏第 6 条）
3. 对比目标（第三版）：负样本拉低结合打分 → 特异性

### 与 ODesign 的四条差异
几何复现 → 结合代理目标 | 无负设计 → 脱靶对抗 | 单构象 → apo/holo 系综 | 几何过滤 → zero-shot 靶标严格协议

## 四、验证协议（纯计算三支柱）

### 支柱 1：zero-shot 靶标严格基准（防泄漏第一）
- **三重隔离划分**：配体级隔离（测试配体训练期不可见）× 结构簇 holdout（TM0.45 + CD-HIT 0.8 预聚类，簇级 8:1:1）× 时间切分（训练 ≤ 阈值日期）
- 测试靶标：8-10 个零结构零序列先验新靶标（AptaDB/SPIRAL 挑选，化学空间分层）
- 评估：生成 100-400 候选/靶标 → AF3 复折叠 → 界面指标（ipTM/iPAE/界面 RMSD）→ 成功率
- **严格口径**：无长度提示、无 hotspot 提示（对照 ODesign 77.95% 的宽松口径如实报告差异）

### 支柱 2：双预测器交叉自洽 + 负对照特异性
- AF3（评估主）+ RhoFold+（交叉验证）；报告 ground truth 自洽上界（RNA-FrameFlow 43.7% 教训，区分模型误差与预测器误差）
- 负对照：同一候选 + 替换靶标（随机/同家族）→ 结合保真度显著下降 → 特异性指标（NCE 负对照效应）

### 支柱 3：公开功能数据验证（无结构，仅功能）
- Eterna：OpenKnot/现有谜题结构验证
- AptaDB：1,230 Kd 序列空间 → 生成序列命中率/相似性（功能先验）
- SELEX 文献：已知适配体家族序列召回

### 消融实验矩阵
| 消融 | 检验 |
|---|---|
| 去靶标上下文（退化为折叠设计） | 靶标条件化的贡献 |
| 去碱基对条件（Module A） | RNAbpFlow +41.7% TM 结论的复现 |
| 去负设计（S3） | 特异性的贡献 |
| 去界面加权 | 结合代理目标的贡献 |
| 阈值稳健性 0.45/0.40/0.35 | 结构聚类敏感度 |

### 8.1 靶标范围定位（2026-08-14 决策）：小分子为主 + 蛋白可行性演示

**前提（数据事实）**：SELEX 实证数据库（AptaDB 1,350 相互作用）蛋白 47.3% > 小分子 29.1%——蛋白是适配体最大市场；但 PDB 的 7,331 个 RNA+蛋白复合物绝大多数是核糖体/剪接体等**组成性结构 RNA**（非适配体-靶标语义），真蛋白适配体结构数据极少且需语义清洗。**方法空白在小分子侧**：ODesign 只支持蛋白靶标；有湿实验的适配体设计（RhoDesign/AlignIF Mango）靶标全是小分子（TO1-biotin）。

**选择**：主体实验用小分子靶标（空白 × 数据质量高的最优解），**但论文内置"蛋白靶标可行性演示"作为主动防御**（非回避）：

| 审稿人预期攻击 | 主动回应 |
|---|---|
| "只覆盖适配体市场一小部分（小分子 29%）" | 小分子 = 模型系统（界面小 → 结合代理目标可测试可消融）；核糖开关 = 自然适配体（细胞真实机制）；AlphaFold/蛋白设计先简单后复杂的领域标准路径 |
| "zero-shot 泛化证据不足（配体种类长尾）" | 严格配体级隔离协议 + 化学空间分层测试靶标 + 如实报告可泛化化学空间边界 |
| "ODesign 框架不是通用吗？你只是换输入" | 差异在结合代理目标进损失 vs 几何复现（AlignIF Kd 变差湿实验证据）+ 负设计 + 严格 zero-shot 协议；ODesign 小分子盲区 = 我们的空白 |
| "蛋白靶标为什么不一起做" | **蛋白可行性演示**：从 7,331 清洗真适配体语义子集（MS2/Rev 肽类）→ 靶标图换残基节点跑通 → 证明架构通用、聚焦是选择 |

**蛋白可行性演示的实施**（M4-M5 里程碑，成本可控）：
- 数据：7,331 中判别适配体语义（核糖体/剪接体排除）→ 预计几十条 + AptaDB 蛋白适配体序列 AF3 蒸馏补充
- 架构：Module B 靶标图节点类型统一（小分子=原子 / 蛋白=残基），无结构性改动
- 报告：小规模性能（如实标注数据量），仅作通用性证据，不进主表
